# Mon App

Application web de gestion sportive (Admin / Coach / Athlète).

## Structure

```
mon-app/
├── index.html       # Structure HTML
├── css/
│   └── style.css    # Tous les styles
└── js/
    └── app.js       # Toute la logique
```

## Branches

| Branche | Rôle |
|---------|------|
| `main`  | Version stable — ne jamais casser |
| `dev`   | Branche de développement — travail quotidien |

## Workflow

1. Travailler sur `dev`
2. Quand une fonctionnalité est stable → merger dans `main`
